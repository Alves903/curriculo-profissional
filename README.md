# 📄 Currículo em HTML - SENAI

Este projeto foi desenvolvido como atividade prática no SENAI com o objetivo de criar uma página web simples utilizando apenas HTML.

## 🚀 Sobre o projeto

A página representa um currículo online contendo:

- Informações pessoais
- Objetivo profissional
- Experiência
- Formação acadêmica
- Habilidades

## 🛠️ Tecnologias utilizadas

- HTML5

## 📚 Objetivo

Praticar a estruturação de páginas web, utilizando tags semânticas e organização de conteúdo sem o uso de CSS ou JavaScript.

## 📂 Estrutura

O projeto contém um único arquivo:

- `index.html` → Página principal do currículo

## ▶️ Como visualizar

1. Baixe o repositório
2. Abra o arquivo `index.html` em qualquer navegador
